# 可靠性引导的置信度加权衰减算法

## 1. 现有系统分析

### 1.1 当前检测逻辑

现有系统采用**多帧累计检测机制**：

```
┌─────────────────────────────────────────────────────────────────┐
│                     传统多帧检测流程                              │
├─────────────────────────────────────────────────────────────────┤
│  1. 每帧检测 → 判断置信度 ≥ alert_conf_threshold (默认0.8)        │
│  2. 阳性帧计数器 +1                                              │
│  3. 阳性帧数 ≥ required_frames (默认5) → 触发告警                 │
│  4. 告警后清零，重新开始计数                                      │
└─────────────────────────────────────────────────────────────────┘
```

**核心问题**：

- 所有检测帧**权重相等**，低置信度误检同样占据计数名额
- 历史帧**无衰减机制**，早期低质量检测长期影响决策
- 未考虑**图像质量因素**（光照、模糊度）对检测可靠性的影响

### 1.2 现有代码结构

# DetectionHistory 类（当前实现）
class DetectionHistory:
    def __init__(self, max_history: int = 100):
        self.frames = []  # 简单列表存储

        # 仅记录原始检测结果，无权重计算
        self.frames.append({
            'spaghetti': has_spaghetti,
            'boxes': boxes,
            'conf': max_conf,
            'area': total_area,

        # 简单计数阳性帧数
        positive_count = len([f for f in self.frames if f['spaghetti']])
        if positive_count >= required_frames:
            return True, "触发告警"

## 3. 算法详细设计

### 3.1 置信度加权机制

#### 3.1.1 基础置信度权重

为每帧检测结果赋予与其置信度成正比的动态权重：

```
W_base(t) = conf(t) / conf_max

其中：
- conf(t): 第t帧的最大检测置信度
- conf_max: 理论最大置信度（通常为1.0）
- W_base(t) ∈ [0, 1]
```

**设计 rationale**：

- 高置信度检测（如0.95）权重接近1，对决策起主导作用
- 低置信度检测（如0.5）权重仅0.5，影响力显著降低
- 避免传统方法的"一票否决"问题

#### 3.1.2 加权累计分数计算

```
S_weighted = Σ [W_base(t) × I_defect(t)]

其中：
- I_defect(t): 缺陷指示函数（检测到缺陷为1，否则为0）
- S_weighted: 加权累计分数
```

**告警触发条件**：

```
S_weighted ≥ S_threshold

其中 S_threshold 为加权阈值（如3.0，相当于3帧高置信度检测）
```

***

### 3.2 指数衰减机制

#### 3.2.1 时序衰减权重

引入指数衰减因子，使历史置信度随时间推移逐步衰减：

```
W_decay(t, t_now) = exp(-λ × (t_now - t))

其中：
- λ: 衰减系数（控制衰减速率，如λ=0.1表示约10秒半衰期）
- t_now: 当前时间戳
- t: 历史帧时间戳
- W_decay ∈ (0, 1]
```

#### 3.2.2 综合权重计算

```
W_total(t) = W_base(t) × W_decay(t, t_now)
           = conf(t) × exp(-λ × Δt)
```

#### 3.2.3 衰减池更新策略

```python
# 伪代码：指数衰减池更新
class DecayPool:
    def __init__(self, decay_lambda=0.1):
        self.entries = []  # (timestamp, base_weight)
        self.lambda = decay_lambda
    
    def add(self, timestamp, base_weight):
        """添加新检测结果"""
        self.entries.append((timestamp, base_weight))
        self._cleanup()  # 清理过期条目
    
    def get_weighted_sum(self, current_time):
        """计算当前加权总分"""
        total = 0
        for t, w_base in self.entries:
            decay = math.exp(-self.lambda * (current_time - t))
            total += w_base * decay
        return total
    
    def _cleanup(self):
        """清理权重低于阈值的过期条目（优化内存）"""
        threshold = 0.01  # 可配置
        current_time = time.time()
        self.entries = [
            (t, w) for t, w in self.entries 
            if w * math.exp(-self.lambda * (current_time - t)) > threshold
        ]
```

### 3.3 感知可靠性系数

#### 3.3.1 图像质量评估指标

**光照强度评估**：

```
brightness_score = f(I_mean, I_median, I_percentile)

其中：
- I_mean: 图像平均亮度
- I_median: 图像亮度中位数（抗极端值）
- I_percentile: 亮度分位数（如25%分位，评估暗部）

综合亮度评分：
I_composite = 0.6 × I_median + 0.4 × I_25percentile

光照可靠性系数：
R_light = min(1.0, I_composite / I_optimal)

其中 I_optimal 为最佳亮度参考值（如128）
```

**模糊度评估**：

```
blur_score = Laplacian_variance(gray_image)

模糊可靠性系数：
R_blur = min(1.0, blur_score / blur_optimal)

其中 blur_optimal 为最佳清晰度参考值（如200）
```

#### 3.3.2 综合感知可靠性系数

```
R_perceptual = α × R_light + β × R_blur + γ × R_other

约束条件：
- α + β + γ = 1.0
- 默认配置：α=0.4, β=0.4, γ=0.2（可根据场景调整）
- R_perceptual ∈ [0, 1]
```

#### 3.3.3 质量调制后的置信度权重

```
W_final(t) = W_base(t) × W_decay(t) × R_perceptual(t)
           = conf(t) × exp(-λ × Δt) × R_perceptual(t)
```

### 3.4 完整算法流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         单帧处理流程                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  输入: 图像帧 I(t)                                                           │
│                                                                             │
│  Step 1: 图像质量评估                                                         │
│    ├─ 亮度检测 → I_composite(t)                                              │
│    ├─ 模糊检测 → blur_score(t)                                               │
│    └─ 计算 R_perceptual(t) = f(I_composite, blur_score)                      │
│                                                                             │
│  Step 2: YOLO缺陷检测                                                         │
│    ├─ 执行推理 → 检测框列表 boxes(t)                                          │
│    └─ 提取最大置信度 → conf_max(t)                                            │
│                                                                             │
│  Step 3: 权重计算                                                             │
│    ├─ 基础权重: W_base = conf_max(t)                                         │
│    ├─ 质量调制: W_quality = W_base × R_perceptual(t)                         │
│    └─ 时序衰减: W_final = W_quality × exp(-λ × Δt)                           │
│                                                                             │
│  Step 4: 更新衰减池                                                           │
│    └─ 将 (timestamp, W_quality) 加入衰减池                                    │
│                                                                             │
│  Step 5: 决策判断                                                             │
│    ├─ 计算当前加权总分: S_total = Σ W_final(i)                               │
│    ├─ 比较: S_total ≥ S_threshold ?                                          │
│    └─ 触发告警 / 继续监控                                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 与传统方法的对比

### 6.1 场景对比分析

| 场景              | 传统方法    | 置信度加权方法         | 改进效果 |
| --------------- | ------- | --------------- | ---- |
| 5帧高置信度(0.9+)检测  | ✅ 正确触发  | ✅ 快速触发 (S≈4.5)  | 响应更快 |
| 5帧低置信度(0.5)检测   | ❌ 误触发   | ✅ 不触发 (S≈2.5<3) | 减少误报 |
| 3帧高置信度 + 2帧低置信度 | ❌ 误触发   | ✅ 可能不触发         | 更精准  |
| 早期高置信度 + 后期低置信度 | ❌ 可能误触发 | ✅ 早期权重衰减        | 时序鲁棒 |
| 低光照环境检测         | ❌ 可能误触发 | ✅ 权重降低          | 质量感知 |
| 模糊图像检测          | ❌ 可能误触发 | ✅ 权重降低          | 质量感知 |

### 6.2 数学对比

**传统方法**：

```
Alert = Σ I(conf_i ≥ 0.8) ≥ 5

问题：
- conf = 0.81 和 conf = 0.99 贡献相同
- 5帧0.5置信度会误触发（实际可信度低）
```

**置信度加权方法**：

```
S = Σ conf_i × exp(-λ × Δt_i) × R_perceptual_i
Alert = S ≥ 3.0

优势：
- 高置信度(0.99)贡献0.99，低置信度(0.5)仅贡献0.5
- 5帧0.5置信度：S ≈ 2.5 < 3.0，不会误触发
- 时序衰减确保近期检测主导决策
- 质量系数降低低质量图像影响
```

2. **配置降级**：如果新配置项不存在，使用默认值保持行为一致
3. **调试支持**：增加加权分数的日志输出，便于调优

## 8. 调优指南

### 8.1 参数调优流程

```
Step 1: 采集测试数据集
    └─ 包含正常/异常/边界情况的视频片段

Step 2: 标定质量参数
    ├─ 在典型光照环境下记录 I_composite 范围
    ├─ 在正常/抖动情况下记录 laplacian_var 范围
    └─ 设置 optimal_brightness 和 optimal_laplacian

Step 3: 调优加权阈值
    ├─ 固定 decay_lambda = 0.1
    ├─ 从 weighted_threshold = 3.0 开始
    ├─ 测试误报率（应显著降低）
    └─ 测试漏报率（应在可接受范围）

Step 4: 调优衰减系数
    ├─ 固定 weighted_threshold
    ├─ 调整 decay_lambda 平衡响应速度 vs 稳定性
    └─ 检测间隔短（<2s）则减小λ，长（>5s）则增大λ

Step 5: 联合优化
    └─ 微调各参数达到最佳平衡点
```

### 8.2 常见问题排查

| 问题现象     | 可能原因                   | 解决方案        |
| -------- | ---------------------- | ----------- |
| 告警响应过慢   | weighted\_threshold 过高 | 适当降低阈值      |
| 仍有误触发    | 质量评估不准确                | 调整光照/模糊阈值   |
| 低质量图像被计入 | R\_perceptual 权重不足     | 增大质量权重或降低阈值 |
| 历史帧影响过大  | decay\_lambda 过小       | 增大衰减系数      |
| 近期检测被忽略  | decay\_lambda 过大       | 减小衰减系数      |

***

## 9. 总结

本改进策略通过三个核心机制提升缺陷检测的准确性和鲁棒性：

1. **置信度加权**：高置信度检测主导决策，减少低置信度误检影响
2. **指数衰减**：历史权重随时间衰减，确保决策聚焦近期观测
3. **感知可靠性**：综合图像质量因素，从源头降低质量不佳导致的误判

该方案在保持系统实时性的同时，显著提升了复杂环境下的检测可靠性，特别适用于光照变化大、相机易抖动等实际工业场景。
